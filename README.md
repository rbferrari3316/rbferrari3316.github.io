# Yueting Deng — Academic Homepage

This folder contains a minimal academic homepage suitable for GitHub Pages and OpenReview profile verification.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `yourusername.github.io`.
2. Upload `index.html` to the repository root.
3. If the repository is named `yourusername.github.io`, GitHub Pages will normally publish it automatically.
4. Otherwise, open **Settings → Pages**, choose **Deploy from a branch**, then select the `main` branch and `/ (root)`.
5. After deployment, copy the public URL into the **Homepage URL** field in OpenReview.
